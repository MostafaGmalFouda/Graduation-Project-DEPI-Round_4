# 🌟 Bright AI

### *An Intelligent End-to-End Data Analysis & Machine Learning Platform*

> **DEPI Graduation Project -- Round 4 (July 2026)**

## 🚀 Overview

Bright AI is an intelligent all-in-one platform that automates the
complete data analysis workflow, enabling users to transform raw
datasets into reliable insights with minimal effort and no coding
experience.

From uploading a dataset to preprocessing, visualization, machine
learning, NLP analysis, and a context-aware RAG chatbot, Bright AI
provides a complete AI-powered analytics experience.

## ✨ Key Features

-   Automatic dataset type detection
-   Smart EDA & preprocessing
-   Interactive visualization dashboard
-   Automated ML pipeline
-   NLP pipeline for text datasets
-   Context-aware RAG chatbot
-   User Mode & Developer Mode
-   Exportable reports and trained models

## 🏗️ Workflow

1.  Upload Dataset
2.  Detect Dataset Type
3.  Automated Preprocessing
4.  Visualization & Reports
5.  Machine Learning / NLP
6.  RAG Chatbot
